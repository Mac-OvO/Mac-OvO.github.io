Mac-OvO 源

一个简洁、清透的 Sileo 软件源主页。支持 Rootless 与 roothide 分类展示，适合 GitHub Pages 直接部署。

源地址
https://mac-ovo.github.io/
将此地址添加到 Sileo / Zebra / Installer
在 Sileo 中打开

源简介

这里用于托管你的 iOS 越狱软件包，你可以把不同架构或不同环境的插件分别整理到不同分类中。 当前推荐分组为：

Rootless
roothide
iphoneos-arm64
iphoneos-arm64e
✓ 源已启用 GitHub Pages，可直接用于 Sileo

快速信息

仓库名称 Mac-OvO.github.io
支持客户端 Sileo / Zebra / Installer
推荐地址 https://mac-ovo.github.io/

roothide 分类

适合放置隐根环境使用的软件包，你可以将这类插件统一在 Section 中设置为 roothide。

目录建议 debs-roothide/
Section 建议 roothide
Architecture 常见写法 iphoneos-arm64e

Rootless 分类

适合放置无根环境软件包，你可以将这类插件统一在 Section 中设置为 Rootless。

目录建议 debs-rootless/
Section 建议 Rootless
Architecture 常见写法 iphoneos-arm64

添加方式

  1. 1
    打开 Sileo，进入 软件源 页面。
  2. 2
    点击右上角添加按钮，输入源地址：https://mac-ovo.github.io/
  3. 3
    确认添加后等待刷新完成，即可在分类中查看 roothide 与 Rootless 软件包。
